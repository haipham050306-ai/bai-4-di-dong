# Student Manager

Ứng dụng quản lý sinh viên viết bằng React Native và Expo. Giao diện tự chọn tiếng Việt hoặc tiếng Anh theo ngôn ngữ ưu tiên của thiết bị.

## Chạy ứng dụng

1. Cài Node.js LTS.
2. Trong thư mục dự án, chạy `npm install`.
3. Chạy `npm start`, sau đó mở bằng Expo Go hoặc khởi chạy emulator Android/iOS.

## Chức năng

- Danh sách sinh viên, tìm kiếm theo họ tên, mã số hoặc email.
- Xem chi tiết, thêm, sửa và xóa sinh viên.
- Xác nhận trước khi lưu thay đổi vào hồ sơ hiện có hoặc xóa hồ sơ.
- Ảnh đại diện từ thư viện thiết bị hoặc URL.
- Dữ liệu lưu cục bộ trên thiết bị bằng AsyncStorage.

Ứng dụng cần quyền truy cập thư viện ảnh khi người dùng chọn ảnh từ thiết bị.
